## Overview

This App is a comprehensive lottery-based event management application designed to provide fair and transparent event access through a randomized selection system. The app serves three main user types: entrants who want to participate in events, organizers who create and manage events, and administrators who oversee platform integrity.

Whether you're looking to join exciting community events, organize your own lottery-based activities, or maintain platform standards, Pathos App provides all the tools you need in a sleek, user-friendly interface.

### Key Features

- **Lottery-based event registration** - Fair chance for everyone
- **QR code scanning** - Easy event discovery and check-in
- **Real-time notifications** - Stay updated on your lottery status
- **Admin dashboard** - Comprehensive platform management
- **Geolocation verification** - Location-based event access, Part 4 
- **Image upload** - Event posters and profile pictures
